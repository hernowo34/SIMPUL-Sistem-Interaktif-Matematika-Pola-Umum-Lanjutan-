# SIMPUL-Sistem-Interaktif-Matematika-Pola-Umum-Lanjutan-
Aplikasi web edukasi matematika (Python Flask) untuk siswa SMP. Menyajikan Visualizer Collatz Conjecture interaktif dan Kuis Pola Generatif dengan tingkat kesulitan bertahap (scaffolding) dan UI Drag &amp; Drop. Dirancang mudah diakses secara lokal via LAN.
